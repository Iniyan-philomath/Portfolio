# Iniyan P. — Embedded AI Engineer

A React portfolio built with Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

Import this GitHub repository into Vercel. Vercel detects Vite automatically; use
`npm run build` as the build command and `dist` as the output directory. New pushes
to `main` will trigger production deployments automatically.
